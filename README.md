# 📅 Interactive Wall Calendar

A fully responsive and interactive wall calendar web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- 📆 Dynamic monthly calendar view
- 🔁 Month navigation (previous/next)
- 📌 Date range selection (start and end dates)
- 🎯 Highlight selected range
- 📝 Notes section for each month
- 💾 Persistent notes using LocalStorage
- 📱 Responsive design (mobile + desktop)
- 🎨 Clean and modern UI inspired by physical wall calendars

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
